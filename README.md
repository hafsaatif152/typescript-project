# TypeScript Projects

My beginner TypeScript projects.

## 1. Todo App
Add, complete, remove and list todos.
Run: `npx tsx todo-app/todo.ts`

## 2. Grade Manager
Manages students' marks, calculates average and grade.
Run: `npx tsx grade-manager/grades.ts`

## 3. Weather App
Fetches real weather using the Open-Meteo API.
Run: `npx tsx weather-app/weather.ts`
